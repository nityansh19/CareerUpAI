# UX Guidelines

CareerUpAI should feel focused and useful before it feels visually impressive.

## Principles

- Put the primary user goal first on each page.
- Keep important actions easy to find and describe them with clear language.
- Prefer progressive disclosure over crowded screens.
- Use animation to explain transitions or hierarchy, not to delay interaction.
- Provide useful empty states instead of blank containers.
- Keep loading and error feedback close to the action that caused it.

## Consistency

Reuse spacing, typography, button patterns and card behavior across features. New UI should look like part of the same product instead of an isolated experiment.

## Responsive design

Design mobile behavior intentionally rather than simply shrinking the desktop layout.
